Возможности

Один репозиторий вместо пяти разрозненных проектов

Арсенал устроен как система: цели, проверки, пайплайн и отчётность связаны общими правилами.

Целевые системы в одном репо

hh.ru, guap.ru и amoCRM описаны в одном монорепозитории: один клон — весь арсенал проверок под рукой.

Контракты и тесты

Ожидания к каждой цели зафиксированы как контракты, а проверки подтверждают их при каждом запуске.

Общий пайплайн

Один пайплайн прогоняет все цели по единым правилам: запуск, окружение и отчётность одинаковы для всех.

Разбор результатов

Результаты приходят в едином формате: сразу видно, какая цель упала, на каком контракте и почему.

Отчёты и история

Прогоны сохраняются: динамика по каждой цели видна между запусками, без ручной сборки логов.

Стандарты для всех таргетов

Общие правила кода, структуры и нейминга: новая цель подключается по готовому шаблону, а не с нуля.

Общий пайплайн

Разбор результата
